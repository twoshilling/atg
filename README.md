# ATG Tracker

A phone-first tracker for ATG (Knees Over Toes) protocols: Hip, Groin, Shoulder, General ATG muscle and IT band.

- Tracks sets against weekly minimums across all protocols, counting shared exercises once at the highest target
- Today's workout sized to 15, 30 or 45 minutes, spaced across the week, with swaps and priorities
- Tap circles to log sets, hold to delete, weight per exercise, timers for holds
- Progress trends, streaks, a weekly wrap and a plain log
- Data is saved in the browser on your device; export a CSV or full backup from the Protocols tab

It's a single `index.html` with no build step. To use it on an iPhone, open it in Safari (e.g. via GitHub Pages) and choose Share › Add to Home Screen.
